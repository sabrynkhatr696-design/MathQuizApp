# 🎯 Math Quiz App

An interactive and colorful Math Quiz web app built using **Python**, **Streamlit**, and **SQLite**.

---

## 🚀 Live Demo
👉 https://mxxe2lj5epdg7ubza96q6s.streamlit.app

---

## 💡 Features

- 🔐 User Registration & Login system  
- 🎮 Interactive quiz with Next question navigation  
- 📊 Score calculation out of 10  
- 🎨 Colorful and engaging UI (kid-friendly design)  
- 🧠 Multiple difficulty levels (easy / medium / hard)  
- 💾 SQLite database integration  

---

## 🧠 How it works

1. User logs in or registers  
2. Chooses difficulty level  
3. Answers questions one by one  
4. Gets final score out of 10  

---

## 🛠️ Technologies Used

- Python 🐍  
- Streamlit 🌐  
- SQLite 🗄️
